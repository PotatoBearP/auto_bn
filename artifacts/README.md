# 图片分类

| 目录 | 内容 |
| --- | --- |
| `runtime/encounter/` | 遭遇战识别截图、绿色框标注与结果 |
| `runtime/deployment/` | 布阵与开战前后截图、结果 |
| `runtime/combat/` | 最新战斗前后截图、技能覆盖预览与决策日志 |
| `runtime/ocr/` | OCR 临时输入与文字识别结果，固定文件名覆盖保存 |
| `validation/skills/` | 一、二技能的人工验证截图 |
| `development/` | 早期开发截图、棋盘校准、拖动测试与旧识别图片 |

实际识别模板单独保存在 `../assets/templates/`，不会作为截图清理。

运行截图只保留固定名称的最新结果，不按每个候选目标创建历史文件。旧开发图片已归档，未删除。
